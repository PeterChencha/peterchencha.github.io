# peterchencha.github.io

Public, static pages for the **Hermes Career Pipeline** — a personal, single-user job-search
automation that runs on its author's own computer.

The site exists for one unglamorous reason: Google requires a public home page, privacy policy and
terms of service before an OAuth application can leave *Testing* status, and a Testing app's refresh
tokens expire every seven days. These pages are what let the automation hold a durable grant.

| Page | Purpose |
|---|---|
| `index.html` | what the application is, and that it is not offered as a service |
| `privacy.html` | exactly which Google data it touches, where that data goes, how to revoke access |
| `terms.html` | personal-use terms; no warranty |

Nothing here is generated from the pipeline. No personal data, no analytics, no cookies, no
client-side scripts. Served by GitHub Pages from `main`.

Related repositories: the code is `career-pipeline-os` (private); the data is `career-data` (private).
